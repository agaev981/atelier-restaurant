# ATELIER — landing page ресторана премиум-класса

Одностраничный сайт ресторана авторской кухни: тёмная тема, акценты тёплого золота,
микроанимации, интерактивное меню с табами, форма бронирования с валидацией,
мобильное меню и плавающая кнопка брони.

## Стек

- Чистые HTML / CSS / JavaScript — без зависимостей и сборки
- Google Fonts: Cormorant Garamond + Manrope
- Изображения-плейсхолдеры — Unsplash
- Карта — OpenStreetMap embed

## Запуск локально

Статический сайт, достаточно открыть `index.html` в браузере или запустить любой
статический сервер:

```bash
python -m http.server 8080
# или
npx serve .
```

и открыть http://localhost:8080

## Структура

```
index.html      — разметка всех секций
css/style.css   — тема, компоненты, адаптив (mobile-first breakpoints)
js/main.js      — меню-табы, бургер, форма, маска телефона, модалка, reveal-анимации
```
